# ホラー演出の画像

`nightmares.webp` は、このゲームのために2026-10-20に画像生成ツールで制作した独自の6場面アトラスです。映画の静止画、俳優の写真、外部の配布素材は使用していません。

配置は左上から「テレビのある居間」「浴室の鏡」「濡れた日記」、左下から「中庭の井戸」「玄関」「迫る白い服の影」。各セルは512×512で、全体は1536×1024。CSSで部屋に合うセルを表示します。

元のPNGは制作環境の `/workspace/generated_images/exec-062fa436-53ad-480f-90ea-a138a7e678bb.png`。Sharpで画素を変えないWebPへの可逆変換を行い、変換前後のRAW画素の一致を確認しました。元PNGも制作環境に保持しています。

元の生成プロンプトは、夜の日本家屋・呪いの映像・濡れた鏡・日記・石の井戸・出口・黒髪と白い服の幽霊を描く、文字や流血のない6場面のホラー背景です。特定の俳優の外見や映画の場面の再現は指定していません。
