# SMALL WORLDS

個人開発者向けの、複数のブラウザゲームを育てる基盤です。TypeScript・React・Vite を使用し、設定ファイルと共通エンジンからゲームを動かします。スマートフォンを優先し、登録なしで遊べます。

- **夜空のおにぎり屋台**：焼き色を見て裏返し、注文どおりの味で出す料理・屋台経営ゲーム。`/?game=night-stall`。約1分の体験と3夜の成長モード。詳細は [屋台ゲーム](docs/stall.md)
- **タワー運営ラボ**：架空のマンションで、住民・資産・備えを育てる新しい小規模ゲーム
- **ラスト・エレベーター**：停電タワーで住民を救出する約3分のルート戦略ゲーム。`/?game=last-elevator` または一覧の新作バナーから開始
- **島のまちづくり**：同じエンジン・画面を別のJSON設定で動かす小さなゲーム
- **タワマン理事長！原作版**：提供された既存ゲームを `/legacy/` に保持。新しいゲームは原作の全機能の移植ではありません

## 開発する

Node.js 24 と npm を使用します。クラウド環境の作業場所は `/workspace/game` です。

```sh
npm ci
npm run dev
```

開発サーバーはポート **5173**。原作版は `/legacy/` です。既存のチェックアウトを使用し、通常は追加の Git worktree を作りません。API キー・DB・認証サービスは不要です。

```sh
npm run build       # TypeScript検査と本番ビルド。出力先は build/
npm test            # 新しいエンジンと原作版のテスト
npm run test:e2e    # ビルド済み成果物のブラウザ検証
npm run preview     # build/ をポート4173で配信
```

まとめて検証する場合は `npm run check`。Playwright はクラウド環境にある `/usr/bin/chromium` を使います。それがない環境では `npx playwright install chromium`、Linuxでシステム依存も必要なら `npx playwright install --with-deps chromium` を先に実行してください。CI は Playwright 指定の Chromium を使います。

`npm run build:demo` で、ゲーム一覧を単一HTMLにまとめた `build/small-worlds-demo.html` と、救出ゲームから直接始まる `build/last-elevator.html`、屋台ゲームの `build/night-stall.html` を作れます。配信サーバーやインストールなしで試すためのファイルです。保存が制限された閲覧環境では警告が出ます。オフラインの結果共有には公開URLを含めません。原作版へのリンクは既存の公開サイトを開きます。

## 構成

| 場所                       | 役割                                                 |
| -------------------------- | ---------------------------------------------------- |
| `src/core/schema.ts`       | JSON設定の型・実行時検証                             |
| `src/core/engine.ts`       | UIに依存しない進行・分岐・相場・診断                 |
| `src/core/storage.ts`      | バージョン付き保存と選択履歴の再実行                 |
| `src/games/*.json`         | イベント・選択肢・人口・資産・満足度・診断などの設定 |
| `src/games/index.ts`       | ゲームの登録                                         |
| `src/ui/`                  | React画面とスマートフォン対応のCSS                   |
| `src/rescue/`              | 救出ゲームの設定・純粋なエンジン・保存・画面         |
| `src/stall/`               | 屋台ゲームの設定・調理エンジン・保存・画面           |
| `public/legacy/`           | 元ゲームのソース。ビルドでそのままコピーする         |
| `src/core/engine.test.ts`  | 新エンジン・データ・保存のテスト                     |
| `tests/`                   | 原作版の48件のテストとUIハンドラー確認               |
| `e2e/`                     | スマートフォン・デスクトップのPlaywrightテスト       |
| `.github/workflows/ci.yml` | テスト・型検査・ビルド。デプロイは実行しない         |
| `build/`                   | 配信成果物。生成物なのでGitに含めない                |

## ゲームの仕組み

短縮モードは10回の決断・約5分、通常モードは24回・約15分です。いずれも時間制限はありません。

選択には人・資金・未来への投資の方針があり、同じ方針が3回以上続くとプラス効果が40%になり、満足にも負担が生まれます。先行投資は数年後に効果が現れ、交流会や設備導入の履歴によって将来のイベントが変わります。資金が0、または満足が10以下になると途中終了します。

相場と通常イベントにはシード付きの乱数を使い、読み込み直しても抽選をやり直しません。相場条件は選択とは独立です。診断は実際の選択の傾向から作り、最終資産や運で性格が変わることはありません。診断は娯楽であり、心理検査ではありません。

保存はゲームごとに独立したブラウザの localStorage を使います。結果は共有シート、クリップボード、手動コピーで共有できます。保存できない場合は通知し、遊び続けることはできます。

設定の追加・バランス調整・セーブ互換性は [開発ガイド](docs/development.md) を参照してください。

## Cloudflare Pages で公開する

ビルドコマンドは `npm run build`、出力先は **`build`** です。原作版も同じビルドに含まれます。`wrangler.jsonc` と `public/_headers` を用意しています。

**本番公開は人間の明示的な承認後に実行します。** 通常のCIでは公開しません。Cloudflare Pagesの設定は [公開手順](docs/deployment.md) にまとめています。追加登録を避ける場合は、既存のGitHubアカウントで使える [GitHub Pagesの手動公開](docs/github-pages.md) も用意しています。

## プライバシーと既存版

新しいゲームは氏名・メール・位置情報などを要求せず、ログイン・広告・アクセス解析・外部フォントも使いません。プレイ履歴のサーバー送信は行いません。共有はプレイヤーの操作でのみ実行します。ホスティングサービス自体の通信ログについては公開先のポリシーに従います。

原作版の進行ロジック・ゲームデータ・画面は保持しました。配信場所を `/legacy/` に移動し、共有リンクと結果画像のURLだけを移動先に合わせています。Google Fontsを参照する原作の挙動が残っています。原作の説明・出典は [提供時のREADME](docs/legacy-source.md) にあります。そこにある `dist/` は提供時のパスで、現在は `public/legacy/` です。原作の保存キー `tower-board-v3` と旧版の移行処理も維持しています。ただし異なる公開ドメインのブラウザ保存は自動では移行しません。

元の公開サイトはこの作業では更新しません。原作を新しいエンジンへ全面移植する場合は、会計・物件・シナリオ等の互換性を別途検証します。
