# タワマン理事長！〜住民と資産を守りぬけ〜

東京の実在するタワーマンションを舞台にした非公式のフィクションゲーム。
10年・約5分の「10回の決断」と、30年間の「じっくり版」を選べます。

## すぐ遊ぶ

1. ZIPを展開します。
2. `dist` フォルダ内の `index.html` をChromeやEdgeなどで開きます。
3. 「10回の決断をはじめる」を押します。

インストールやAPIキーは不要。HTML・CSS・JavaScriptだけで動作します。
フォントはGoogle Fontsを参照しますが、接続できない場合も代替フォントで遊べます。
保存先はブラウザのlocalStorageです。ファイルから開いた場合の保存の扱いはブラウザにより異なります。
安定して保存・編集する場合は、エディターのローカルサーバー機能などで `dist` を配信してください。
公開サイトのセーブデータは、ローカルのコピーには自動では移りません。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `dist/index.html` | HTML・遊び方・スクリプト読み込み |
| `dist/style.css` | デザイン・スマホ対応 |
| `dist/app.js` | 画面・操作・保存・結果画像・シェア |
| `dist/engine.js` | 進行・費用・工事・築年数・決算 |
| `dist/campaign-data.js` | 物件別シナリオ・架空住民・相談・物語 |
| `dist/market-data.js` | 開始価格・売出事例・出典 |
| `dist/personality.js` | 選択から作る娯楽用の性格診断 |
| `tests/simulation.test.cjs` | 進行・会計・モード・保存のテスト |
| `tests/ui-smoke.cjs` | 画面テンプレート・操作ハンドラーの確認 |
| `.openai/hosting.json` | 静的配信フォルダの設定例 |

`dist` が配信可能なアプリ本体です。ビルド工程や依存パッケージはありません。
表示文言は主に `app.js`、物語は `campaign-data.js`、バランスは `engine.js`、デザインは `style.css` を編集します。
JavaScriptの読み込み順は `index.html` の順序を維持してください。
公開時に更新したら、`?v=9` の数字も変更すると古いキャッシュが残りにくくなります。

## テスト

Node.js 18以降で、展開したプロジェクトフォルダから実行します。
`npm install` は不要です。

```sh
npm test
npm run test:ui
```

直接実行する場合：

```sh
node --test tests/simulation.test.cjs
node tests/ui-smoke.cjs
```

UIテストはテンプレートとハンドラーの確認です。実機での見た目の確認は含みません。
UIテストはHTMLの `?v=9` を参照するため、バージョン番号を変える場合はテスト側も合わせて更新してください。

## 公開する場合

静的サイトの公開先に `dist` 内の7ファイルを配置してください。
公開サービス側でURLや公開範囲を設定します。
`.openai/hosting.json` は配信設定例で、既存サイトの識別子は含めていません。
GitHubで管理する場合は、展開したフォルダ内のファイルをリポジトリに追加できます。

## データと表現

- 出典はゲーム内にあります。開始価格は2026年10月15日確認の3LDK売出事例を70㎡換算した固定参考値で、自動更新はしません。
- 住民・運営状況・修繕履歴の仮定・出来事・開始後の価格変動・外観は架空設定です。
- 実在の管理組合・管理会社とは関係ありません。
- 性格診断は娯楽であり、心理検査や能力評価ではありません。
