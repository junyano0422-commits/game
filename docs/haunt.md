# 零時の残響

貞子をモチーフにした、オリジナルの非公式短編ホラー脱出ゲームです。長い黒髪・白い服の影、井戸、呪いの映像を使い、部屋の探索と封印の暗号を組み合わせています。公式素材・映像・音源は使わず、本作用の生成画像、CSS、SVGで描画します。

`/?game=zero-echo` または一覧バナーから開始。新規の館探索モードは短編24手・気配18・電池3、じっくり32手・気配22・電池4。約3〜5分を想定し、現実の時間は進行に影響しません。音あり・音なしを選んで遊べます。以前の保存はその夜の手数とルールを維持します。

## 館探索モード（v3）

### 物語・操作・音の見直し

館の片付けに来た主人公が古いビデオを再生し、出口を失う導入を追加しました。`story.ts` に導入・発見時の台詞・意味の説明・結末を設定し、発見順に画面の物語カードへ表示します。日記で少女の過去を知り、井戸で彼女の願いに触れ、集めた記憶に応じて結末の説明を変えます。章は操作履歴から復元し、保存形式と従来のルールを維持。「ここまでの物語」で既知の章を読み返せます。

`TravelPrompt.tsx` は、未確認の映像・日記・鍵の所持や保管・未探索の印を見て目的を案内します。目的地までの次の一部屋を示し、暗号の答えは教えません。スマホでは目的・次の移動・慎重移動・調査・道具・手帳を下部の操作欄にまとめました。`QuickItems.tsx` により、拾う・調合・回復・閃光札の使用は持ち物画面を開かずに行えます。持ち物画面は先に道具を表示し、マップは別タブへ。矢印キーでも切り替えられます。結果文が操作欄に隠れないよう、欄の実測した高さに合わせてスクロールします。玄関の暗号入力は通常のスクロール画面です。

`soundtrack.ts` は実際の操作と発見から再生音を決めます。物資を拾うだけで直前の調査音・足音・台詞を繰り返しません。紙・鏡・金属・布・閃光・拾う音・呼吸の7種を加えて全15種にし、部屋と道具に合わせて鳴らします。足音と水滴の音色、全体音量と環境音のバランスも調整しました。次の行動や中断時は古い効果音と予約した警告を止め、読み上げ中は環境音を下げます。

「物語の声」は端末内の日本語読み上げを使います。無理に声を低くする設定をやめ、利用可能かどうかの表示と試聴を追加。音声一覧が遅れて読み込まれる端末にも対応します。自動の台詞は新しい発見時に1回だけ。物語カードから再読できます。声の自然さは端末によって異なり、録音された声優の音声は含みません。声が使えない端末では理由と字幕を表示します。

追加テストでは、発見順・目的・鍵の保管・結末・拾う操作による音の再発防止を確認します。ブラウザでは360×740の画面で結果が操作欄に隠れないこと、道具と移動を直接操作しての完走、遅れて利用可能になるローカル音声の試聴・台詞の回数を確認。合成音15種は実際のOfflineAudioContextで出力を検査します。これらは人が音の好みや物語の分かりやすさを評価した結果ではなく、実機の聞こえ方と遊びやすさは引き続き確認が必要です。

『バイオハザード』の探索・持ち物のやりくり・拠点への帰還・追跡を参考に、独自の館と白い影に組み合わせました。同作品のキャラクター、画像、音源、マップは使用していません。v2の暗号、危険予告、記憶の結末は引き継ぎます。

- 部屋は線でつながる場所だけへ移動できます。居間から浴室・書斎・玄関、書斎から井戸へ。井戸を初めて調べると浴室への近道が開き、帰路が変わります。
- 持ち物は4枠。書斎を調べた後、鍵を実際に拾って井戸へ運びます。鉄格子を開けると鍵は役目を終え、1枠空きます。居間の保管箱で道具を預け、取り出せます。拾う・整理する操作は0手です。
- 布切れ＋浄化粉を1手で調合すると、閃光札になり1枠空きます。閃光札は1手で使い、次の2行動は追跡者を停止。薬草は1手で体力＋2（上限3）、予備電池は1手で電池＋3（上限6）。満タンの道具を誤って消費できません。
- 鍵の発見で白い影が動き始めます。初回は警告の猶予があり、その場で突然攻撃しません。以後、調査の音2・通常移動や道具使用の音1・点灯中のテレビの音1が蓄積し、2以上で影が1部屋近づきます。同室では体力−1、直後の1行動は再攻撃しない猶予があります。
- 居間には影が入らず、通り抜けもしません。ただし呪いと手数は進みます。マップに影の位置、未回収の物資、開通した道を表示し、音なしでも危険を把握できます。
- 慎重な移動は2手と電池1を使い、その移動中は影に追いつかれません。呪いの危険予告への対処は引き続き必要です。足音を正しくやり過ごした直後の移動も追跡を避けます。マップ内の移動ボタンは明記した通常1手で、画面上の慎重移動の設定とは別です。
- 調合・使用も1行動なので影が動きます。持ち物画面を開くだけ、拾う、保管では影も動きません。体力0、気配上限、手数切れで失敗。最後の封印の正答は脱出を優先します。

最初の試作で、覚醒と同時の接触、影が安全拠点を経由する追跡経路を修正しました。3方針を同じ1〜1,000シードで比較すると、警告も道具も無視する最短経路は779回、警告を読み薬草・閃光札を準備する経路は1,000回生還。慎重移動を使う経路も1,000回生還し、平均残体力は準備経路の2.219から3になりましたが、最大手数は18から22に増えました。この固定経路群の比較であり、実際のプレイヤーの勝率や全戦略の最適性を表すものではありません。次の改善では実際に遊んだ人の迷い方と、周回時の変化を確認します。

スマホでは追跡の情報を画像の直下、マップ・持ち物と手帳を横並びに配置します。マップと持ち物はネイティブダイアログで開き、キーボードのEscapeでも戻れます。体力低下時の接触音と、同室の影による接近演出は既存の音量・演出設定に従います。

## 改善版のルールと解法

形式v2の保存と、v3の基礎部分に使うルールです。居間の映像は「最後の部屋」、書斎の日記は「残り二つの前後関係」を示します。二つの断片を組み合わせ、浴室・書斎・井戸で得た記号を玄関に並べます。書斎の鍵で井戸への入口が開きます。手がかり帳に断片と記号を自動記録するため、暗記は不要です。

行動は各1手。テレビ点灯中は気配＋1と引き換えに具体的な危険予告を得ます。足音のときの移動、視線のときのライトなしの調査はさらに＋3。ライトは電池1で視線を防ぎ、浴室で得る護符は一度だけ視線から守ります。

足音のときに息をひそめると気配−3（テレビの＋1と合算）となり、直後の1行動が移動なら足音を安全に通過できます。それ以外の場面や連続使用は逆に＋2（点灯中は合計＋3）。固定的な「待つ→移動」を有利にしません。安全な移動の効果は次の1行動までで、別の行動を選ぶと失います。

プラグを抜くと基本の気配増加が止まる代わりに、危険に触れた際の追加量が＋5になります。映像の予告を失っても、部屋の足音・視線は文章で読み取れます。危険の種類と休息の効果を操作前に表示し、乱数で一方的に失敗させないようにします。居間で電源を戻せます。

テレビを点灯したまま各部屋の記号を初めて調べると、映像と重なる記憶を入手します。三つの記憶を集めて生還すると別の結末になります。最後に電源を入れただけでは入手できません。診断は記憶・テレビが点灯していた実際の行動数・足音を避けた回数から決めます。

封印の並べ直しは無料、実行は1手。誤答は気配＋4（点灯中の基本＋1は別途）。正答は最後の手でも脱出を優先します。気配か猶予が限界に達すると夜に取り込まれます。調査済みの場所はボタンを無効にして、意図しない再調査による手数・電池消費を防ぎます。

スマホでは探索画面を圧縮し、行動結果を操作ボタンの直前へ配置。長い結果文は展開でき、手がかり帳はネイティブダイアログで開きます。暗号入力時には二つの断片と記号を入力欄のそばにも表示。開始・再開・再挑戦時には画面先頭と見出しへ戻ります。消したテレビの中の影、護符を失った鏡、日記から先に訪れた井戸など、履歴で異変の位置と文章も変化します。

## 構成と保存

`src/haunt/config.ts` に部屋・アイテムの説明、モード資源、予告と基本ルールを配置。`engine.ts` は初版、`revision-config.ts` と `revised.ts` はv2ルールを維持します。`survival-config.ts` にv3の部屋の接続・道具・物資・資源・追跡の設定、`survival.ts` に持ち物・調合・追跡・診断・保存を追加しています。いずれもDOMに依存せず、渡された状態を変更しません。`HauntGame.tsx`・`SurvivalPanel.tsx` と `haunt.css` が表示と入力を担当します。

保存キーは `small-worlds:zero-echo:v1`。シード・モード・操作履歴を保存し、Zod検証後に再実行して状態を復元します。キー名は互換性のため維持し、新規データは形式v3。v1/v2は従来のルールと形式のまま読み込み・続行でき、進行途中に新ルールを差し込みません。v3は道具の操作を含め最大240操作・32,000文字まで。体力・持ち物などの結果の数値を直接信用せず、操作から再計算し、未取得の道具や不正な移動を拒否します。壊れた保存は自動削除せず、新規開始の上書き時に確認。保存を拒否された場合も通知して遊べます。ほかのゲームの保存には触れません。

外部API・マイク・実行中の時計・個人情報入力は不要です。共有ボタンを押したときだけ、結果文を端末の共有機能またはクリップボードへ渡します。共有文に暗号の解答や保存履歴は含めません。

## 画像・音・演出

`assets/nightmares.webp` は6場面をまとめた1536×1024の生成画像です。居間・鏡・日記・井戸・扉・迫る姿を、画像要素の位置指定で切り替えます。元PNGから画素を変えない可逆WebPへ変換し、約1.82 MBにしました。元の生成画像は制作環境の `/workspace/generated_images/exec-062fa436-53ad-480f-90ea-a138a7e678bb.png` に保持しています。画像の出典・配置は `assets/README.md` を参照してください。

通常のWeb版は画像を別のハッシュ付きアセットとして配信し、ホラー画面を開いたときに読み込みます。画像を読み込めない場合は従来のCSS・SVGへ戻ります。単一HTML版は画像もデータURLで内包します。大きな画像URLに対するCSS変数の展開制限を避けるため、背景用画像も実際の `<img>` で表示します。

`audio.ts` がWeb Audioで電話、左右の足音、砂嵐、水滴、扉の軋み、発見音、接近音、夜明けの音など15種類を合成します。環境音は低音のうなりと風、気配が強いと鼓動を重ねます。追加の音源ダウンロードや外部サービスは使いません。`useHorrorMedia.ts` がユーザー操作での開始、消音、音量、非表示・中断・画面終了時の停止を担当。戻った後は再開ボタンを待ちます。既定の音量は55%、ゲインとコンプレッサーで余裕を持たせます。

物語の声は、ブラウザがローカルと報告する日本語のSpeechSynthesis音声がある場合だけ使います。台詞は本作用の独自文です。声がない端末では効果音と文章で進行し、ネットワーク上の読み上げサービスは利用しません。声と画面の接近演出は個別に無効化でき、端末の視覚効果を減らす設定も尊重します。

設定キー `small-worlds:zero-echo:media:v1` に音・声・音量・演出の好みだけを保存します。ゲーム進行とは別に保存します。音を消しても、危険の予告と結果は画面に表示します。

## 検証と配布

`npm run check` で全ゲームの検証を実行します。単体テストでは初版の100シード×2モードに加え、改善版の危険に合わせる戦略と従来の固定戦略を1,000シードで比較します。改善版は100シード×2モード×2つの探索方針でも完走を確認し、手がかり・鍵・護符・予告・電源の復旧・誤答・両方の失敗条件・保存再実行を検証します。二つの断片から順序が一意に決まることと、v1/v2それぞれの保存再実行も検証します。全ルートの最適性や、全シードの勝率を証明するものではありません。

v3は持ち物の枠数・保管・重複回収防止・鍵の消費・近道・調合・回復上限・追跡・体力切れ・慎重移動のコスト・旧上限を越える行動を単体テストで確認します。`tests/support/survival-policy.ts` に上記3方針の自動探索を置き、1,000シード比較を回帰テスト化。両モードとテレビ点灯/消灯それぞれ100シードで完走・保存の再実行も検証します。PlaywrightはスマホとPCで持ち物の保管・再開、慎重移動とマップ移動、閃光札の調合後に再読込して最後の暗号を画面の断片から解く完走を実操作します。

Playwrightはスマホ・PCで最初から実操作して暗号を解く完走、結末の共有、保存再開、電源復旧、失敗結末、上書きのキャンセル、保存失敗を確認します。改善版では画面先頭への復帰、スマホの結果と操作の表示範囲、手帳のキーボード操作、画面に書かれた二つの断片から解を導く完走、記憶を集めた結末も検証します。追加の音テストでは実際のOfflineAudioContextで15種類の波形が無音でないこと、左右の足音とピークを確認します。実際のAudioContextの開始・消音・非表示時の停止・手動再開・終了時の解放、設定の保持、音や画像が使えない場合の継続も検証。単一HTMLから別の画像リクエストなしで画像が表示されることも確認します。実機Safariと各端末の読み上げ音声の音質は未検証です。

`npm run build:demo` で単一HTMLの `build/zero-echo.html` を生成。端末によってローカルHTMLの実行・保存に制限があるため、スマホでは承認後に公開URLで提供する想定です。公開ブランチの `zero-echo.html` に追加すれば既存ゲームのURLを維持できます。制作・テストだけでは本番公開せず、人間の承認を得てから行います。
