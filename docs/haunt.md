# 零時の残響

貞子をモチーフにした、オリジナルの非公式短編ホラー脱出ゲームです。長い黒髪・白い服の影、井戸、呪いの映像を使い、部屋の探索と封印の暗号を組み合わせています。公式素材・映像・音源は使わず、背景と人物はCSS・SVGで描画します。

`/?game=zero-echo` または一覧バナーから開始。短編は18手・気配14・電池3、じっくりは24手・気配16・電池4。約3〜5分を想定し、現実の時間は進行に影響しません。音声なしで遊べます。

## 改善版のルールと解法

新規ゲームには形式v2のルールを使います。居間の映像は「最後の部屋」、書斎の日記は「残り二つの前後関係」を示します。二つの断片を組み合わせ、浴室・書斎・井戸で得た記号を玄関に並べます。書斎の鍵で井戸への入口が開きます。手がかり帳に断片と記号を自動記録するため、暗記は不要です。

行動は各1手。テレビ点灯中は気配＋1と引き換えに具体的な危険予告を得ます。足音のときの移動、視線のときのライトなしの調査はさらに＋3。ライトは電池1で視線を防ぎ、浴室で得る護符は一度だけ視線から守ります。

足音のときに息をひそめると気配−3（テレビの＋1と合算）となり、直後の1行動が移動なら足音を安全に通過できます。それ以外の場面や連続使用は逆に＋2（点灯中は合計＋3）。固定的な「待つ→移動」を有利にしません。安全な移動の効果は次の1行動までで、別の行動を選ぶと失います。

プラグを抜くと基本の気配増加が止まる代わりに、危険に触れた際の追加量が＋5になります。映像の予告を失っても、部屋の足音・視線は文章で読み取れます。危険の種類と休息の効果を操作前に表示し、乱数で一方的に失敗させないようにします。居間で電源を戻せます。

テレビを点灯したまま各部屋の記号を初めて調べると、映像と重なる記憶を入手します。三つの記憶を集めて生還すると別の結末になります。最後に電源を入れただけでは入手できません。診断は記憶・テレビが点灯していた実際の行動数・足音を避けた回数から決めます。

封印の並べ直しは無料、実行は1手。誤答は気配＋4（点灯中の基本＋1は別途）。正答は最後の手でも脱出を優先します。気配か猶予が限界に達すると夜に取り込まれます。調査済みの場所はボタンを無効にして、意図しない再調査による手数・電池消費を防ぎます。

スマホでは探索画面を圧縮し、行動結果を操作ボタンの直前へ配置。長い結果文は展開でき、手がかり帳はネイティブダイアログで開きます。暗号入力時には二つの断片と記号を入力欄のそばにも表示。開始・再開・再挑戦時には画面先頭と見出しへ戻ります。消したテレビの中の影、護符を失った鏡、日記から先に訪れた井戸など、履歴で異変の位置と文章も変化します。

## 構成と保存

`src/haunt/config.ts` に部屋・アイテムの説明、モード資源、予告と基本ルールを配置。`engine.ts` は初版ルールを維持し、`revision-config.ts` と `revised.ts` が改善版のコスト・断片・異変・結末を扱います。どちらもDOMに依存せず、渡された状態を変更しません。`HauntGame.tsx` と `haunt.css` が表示と入力を担当します。

保存キーは `small-worlds:zero-echo:v1`。シード・モード・操作履歴を保存し、Zod検証後に再実行して状態を復元します。キー名は互換性のため維持し、新規データの形式をv2にしています。初版の形式v1は従来ルールのまま読み込み・続行でき、進行途中に新ルールを差し込みません。最大24手・サイズ上限つきで、未到達の井戸や不正な操作を拒否します。壊れた保存は自動削除せず、新規開始の上書き時に確認。保存を拒否された場合も通知して遊べます。ほかのゲームの保存には触れません。

外部通信・音声・実行中の時計・個人情報入力は不要です。共有ボタンを押したときだけ、結果文を端末の共有機能またはクリップボードへ渡します。共有文に暗号の解答や保存履歴は含めません。

## 検証と配布

`npm run check` で全ゲームの検証を実行します。単体テストでは初版の100シード×2モードに加え、改善版の危険に合わせる戦略と従来の固定戦略を1,000シードで比較します。改善版は100シード×2モード×2つの探索方針でも完走を確認し、手がかり・鍵・護符・予告・電源の復旧・誤答・両方の失敗条件・保存再実行を検証します。二つの断片から順序が一意に決まることと、v1/v2それぞれの保存再実行も検証します。全ルートの最適性や、全シードの勝率を証明するものではありません。

Playwrightはスマホ・PCで最初から実操作して暗号を解く完走、結末の共有、保存再開、電源復旧、失敗結末、上書きのキャンセル、保存失敗を確認します。改善版では画面先頭への復帰、スマホの結果と操作の表示範囲、手帳のキーボード操作、画面に書かれた二つの断片から解を導く完走、記憶を集めた結末も検証します。実機Safariは未検証です。

`npm run build:demo` で単一HTMLの `build/zero-echo.html` を生成。端末によってローカルHTMLの実行・保存に制限があるため、スマホでは承認後に公開URLで提供する想定です。公開ブランチの `zero-echo.html` に追加すれば既存ゲームのURLを維持できます。制作・テストだけでは本番公開せず、人間の承認を得てから行います。
