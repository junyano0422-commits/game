# 夜空のおにぎり屋台

スマートフォン向けの短時間料理・屋台経営ゲームです。`/?game=night-stall` またはゲーム一覧の「夜空のおにぎり屋台」から始めます。ひと晩体験は約1分、3夜の屋台日記は約3〜5分（調理や設備選びの時間を含む）。1夜の営業時間の上限は通常60秒・体験42秒です。全注文の処理が終わると早めに閉店します。

## 操作と進行

1. 焼き台にお米を置きます。2つの焼き台で同時に焼けます。
2. 焼き加減の針が緑の範囲に来たら裏返し、もう片面も焼いてお皿へ取ります。
3. 注文と同じ味を選び、お客さんの「出す」を押します。皿の上では焦げません。
4. 売上で設備を1つ購入するか、お金を残して次の夜へ進みます。

両面とも緑なら45円、十分に火が通っていれば28円。連続提供で2円ずつ、最大10円のボーナスです。生焼け・焦げ・味の間違いでは売上が入りません。待ちきれなかったお客さんは帰ります。材料は夜ごとに用意されるため、お金を使い切っても次の営業はできます。

提灯は待機時間を延ばし、追加の焼き台は同時調理数を増やし、こだわりのお米は提供単価を上げます。天候・お祭りで焼ける速さや来客間隔も変化します。前の夜に人気だった味は、次の夜の最初に常連客が注文します。結果の診断は丁寧な焼き加減・連続提供・設備選びを反映した娯楽です。

「一時停止」で火と待ち時間の両方が止まります。タブやアプリが非表示になった場合も止め、戻った後は明示的な再開を待ちます。タイトルに戻っている間や、ブラウザを閉じている間には時間を進めません。

## 構成・保存

- `src/stall/config.ts`: モード・味・お客さん・夜のイベント・設備データ
- `src/stall/engine.ts`: DOMに依存しない調理・来店・売上・購入・診断・共有処理
- `src/stall/StallGame.tsx` / `stall.css`: 画面・入力・描画・時計・スマホ表示

保存キーは `small-worlds:night-stall:v1`。形式バージョン・シード・モード・操作履歴だけを保存し、読み込み時に検証して再実行します。連続する時間進行はまとめて記録します。残金などを保存値から直接信用しません。ほかのゲームの保存には触れません。破損保存は自動削除せず、新規開始による上書き時に確認します。保存を利用できないブラウザでは、そのことを表示したうえで遊べます。

外部API・アカウント登録・分析サービス・フォント配信・個人情報入力は使いません。共有はユーザーがボタンを押したときだけ、結果文を端末の共有機能またはクリップボードへ渡します。通信配信する場合のアクセスログは配信先の設定に依存します。

## 検証と配布

`npm run check` で全ゲームのビルド・単体テスト・既存ゲームテスト・Playwrightを実行します。屋台の単体テストは焼き加減、正誤、同時調理、閉店、購入、常連、保存履歴の再実行と不正データの拒否を検証。30シード×2モードで完走します。ブラウザではスマホ・PCで実際の調理と完走、一時停止、保存再開、設備購入、保存失敗を確認します。実機Safariは別途確認が必要です。

`npm run build:demo` で外部ファイルに依存しない `build/night-stall.html` を生成します。ダウンロードしたHTMLは、端末によってファイルURLでの実行・保存に制限があります。Cloudflare Pagesには通常の `build/` を配置できます。

本番公開には人間の承認が必要です。現行の公開ブランチや既存の救出ゲームを、制作やテストだけで差し替えません。承認後は公開ブランチの `night-stall.html` へ追加すれば既存URLを維持して提供できます。
